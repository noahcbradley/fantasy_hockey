# Fantasy Hockey Analyzer

## Requirements

Python 3.13

## Run Instructions

```bash
python -m venv venv
pip install -r requirements.txt
python script.py
```

## Environment File

Create .env file in the root directory with the following environment variables

- MY_ESPN_SWID
- MYFANTASY_ESPN_S2
- PGS_ESPN_S2
- LEAGUE_ID_MY_FANTASY
- LEAGUE_ID_PGS

## Finding Your SWID and ESPN S2

Refer to the following [guide](https://www.gamedaybot.com/help/espn_s2-and-swid/#:~:text=You%20can%20find%20these%20two,%3A%2F%2Ffantasy.espn.com.) to locate your SWID and ESPN S2 keys.
